# Promo Module

The Promo module is a domain wrapper for promotional features such as coupons, discounts, cashback, and vouchers. It reuses campaign logic from the shared campaign module while keeping promo-specific integrations separated.

## Current State
- Wrapper around `CampaignModule`
- Provides a domain namespace for future promo-specific services and controllers
